### Write Access :lock:

Write access is granted to members of `access.managed-code-repositories.gram.production.operator` in the Access Governance Portal.

You can check who already has access in [Scribe](https://scribe.klarna.net/groups/view/?gid=access.8244387.1288598.prod.operator).

If you don't have access, [request it in AGP](https://access.klarna.net/identityiq/ui/rest/redirect?rp1=/ui/index.jsf&rp2=accessRequest/manageAccess/add?filterKeyword=access.managed-code-repositories.gram.production.operator%26quickLink=Request%20Access).
